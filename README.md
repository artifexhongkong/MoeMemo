# MoeMemo — 萌貼備忘錄官方網站

此倉庫僅存放「萌貼備忘錄 MoeMemo」的公開網站內容（門面頁、隱私權政策、版本資訊），**不包含任何應用程式源碼**。

- 網站：https://artifexhongkong.github.io/MoeMemo/
- 隱私權政策：https://artifexhongkong.github.io/MoeMemo/privacy-policy.html
- 版本資訊（App 內更新檢查端點）：https://artifexhongkong.github.io/MoeMemo/version.json

## 維護方式

| 檔案 | 用途 | 更新時機 |
|------|------|----------|
| `index.html` | 官方門面頁（商店「網站」欄位） | 手動 |
| `privacy-policy.html` | 隱私權政策（Play Console「隱私權政策 URL」欄位） | 手動 |
| `version.json` | 最新穩定版本資訊，供 App 內更新檢查讀取 | 每次穩定版發佈由私有倉庫 CI 自動推送 |
